# Voltage

Think of voltage like pressure in a water pipe

* More voltage means more pressure, more pressure means more water can flow. 
* More voltage means more electrons can flow

## Volt

Volt = Joule / Coulomb

Work per group of flowing electrons



# Current

* Current is the flow of electrons, measured in Amperes (Amps), pas a single point in a circuit within a set amount of time
* 1 amp = 1 coulumb
* 1 Coulumb = 6,242,000,000,000,000 electrons per second

Electrons are negatively charge they flow from the negative terminal to the positive terminal

# Types of electricity

There are two types of current electricity

* Alternating Current (AC)
* Direct Current (DC)

## Alternating Current (AC)

In AC the current moves back and forth with the changing magnetic field

This is the type of electricity form wall sockets in your home



## Direct Current (DC)

In DC current travels only in one direction

This is the type of electricity in  batteries
